# 👨‍💻 Jestopher B. Dela Torre | Portfolio Website

> A personal portfolio website showcasing my journey as an IT student, Web Developer, and QA Tester.

## 📖 About The Project

This repository contains the source code for my personal portfolio website. It serves as a central hub to demonstrate my technical skills, showcase my academic and personal projects, and list my certifications in AWS and ServiceNow.

The site is built with a **mobile-first approach**, ensuring a seamless experience across desktop, tablet, and mobile devices.

### ✨ Key Features
* **Responsive Design:** Fully adaptive layout using modern CSS (Flexbox/Grid).
* **Smooth Navigation:** Interactive navigation with a custom hamburger menu for mobile.
* **Project Showcase:** Detailed cards linking to my GitHub repositories.
* **Certification Verification:** Modal popups allowing visitors to view and verify credentials.
* **Functional Contact Form:** Integrated with **EmailJS** for real-time messaging without a backend server.
* **Dark/Modern UI:** Clean aesthetic with custom fonts (Poppins & Inter).

## 🚀 Getting Started

To view this project locally on your machine:

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/JeckTupir/your-repo-name.git](https://github.com/JeckTupir/your-repo-name.git)
    ```
2.  **Navigate to the project directory**
    ```bash
    cd your-repo-name
    ```
3.  **Run the project**
    * Simply open `index.html` in your browser.
    * *Note:* Since the script uses `type="module"`, it is recommended to use the **Live Server** extension in VS Code to avoid CORS issues.
